# 実験ツリー

汎用の実験管理アプリ。ブラウザで `index.html` を開くだけで使えます。サーバー不要。
個人利用のために作ったものなので動作保証はしません。

## 起動方法

`index.html` をブラウザで開く。

## 機能

### ツリービュー（メイン）
実験の親子関係をノードとエッジで可視化します。

- **ドラッグ** — キャンバスをパン
- **マウスホイール** — ズームイン／アウト
- **ノードをクリック** — 右側に詳細パネルを表示
- **ノードをダブルクリック** — 編集モーダルを開く
- **全体表示ボタン** — すべてのノードが収まるよう自動調整

### 実験の追加
- **新規実験**（ヘッダー右上）— ルート実験を追加
- **子実験を追加**（詳細パネル）— 選択中の実験を親として追加。親のパラメータが自動コピーされる

### 実験フォームの項目

| 項目 | 説明 |
|------|------|
| 実験名 | 必須。例: `lr0.001_batch64` |
| 親実験 | どの実験から派生したかを指定 |
| 仮説・動機 | なぜこの実験をするか。ツリーのエッジに表示される |
| タグ | Enter またはカンマで追加。フィルタリングに使用 |
| パラメータ | 入力条件（キー・値の自由入力） |
| 結果 | 実験後に記録する出力値（キー・値の自由入力） |
| コメント | 考察・気づき・次のアクションなど |

### 結果の記録
実験を実行したあと、ノードをクリック → 詳細パネル「**編集**」→ 結果欄に入力して保存。

### 詳細パネル（差分表示）
親実験との差分を色分けして表示します。

- **黄色（△ 変更）** — 親から値が変わったパラメータ
- **緑（+ 追加）** — 親にはなかった新しいパラメータ
- **赤（削除）** — 親にあったが削除されたパラメータ

### リストビュー
全実験を表形式で表示。タグでの絞り込みが可能。

### 比較ビュー
リストビューで複数の実験にチェックを入れ「比較する」を押すと、パラメータと結果を横並びで比較できます。差分セルは黄色でハイライトされます。

## データ管理

### 保存先
データはブラウザの **localStorage** に自動保存されます（キーは `exp_tree_v2`）。

### バックアップ・復元（JSON）
ツリー構造を含む完全なバックアップ。定期的な書き出しを推奨します。

| ボタン | 動作 |
|--------|------|
| **JSON 保存** | 全データを `.json` ファイルに書き出す |
| **JSON 読込** | `.json` ファイルを読み込む。既存データへの追加または置き換えを選択できる |

### CSV エクスポート
**CSV** ボタンで現在の全実験を Excel 対応の CSV ファイルに書き出します。  
※ CSV はデータ閲覧・分析用です。CSV からのインポートには非対応です（ツリー構造の復元には JSON を使用してください）。

## データ構造（JSON）

```json
{
  "version": 1,
  "exportedAt": "2026-05-01T00:00:00.000Z",
  "exps": [
    {
      "id": "一意なID",
      "name": "実験名",
      "parentId": "親実験のID（なければnull）",
      "hypothesis": "仮説・動機",
      "tags": ["tag1", "tag2"],
      "params": { "lr": "0.001", "batch": "32" },
      "results": { "accuracy": "0.85", "loss": "0.42" },
      "comment": "コメント",
      "createdAt": "ISO8601形式",
      "updatedAt": "ISO8601形式"
    }
  ]
}
```
